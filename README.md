Ecossistema digital voltado para engajamento e capacitação corporativa. Conta com arquitetura **Offline-First** (garantindo funcionamento ininterrupto mesmo sem internet e sincronização automática ao restabelecer a conexão), minijogos e dashboards gerenciais.
